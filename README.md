# Roadmaps

Roadmaps com caminhos full stack webdev (pleno -> sênior) e low-level. Os roadmaps foram gerados totalmente pelo Claude com base nas minhas experiências e conhecimentos prévios. Alguns tópicos são apenas para revisão, e outros foram adicionados por curiosidade.
Os roadmaps são divididos por seções, e cada seção possui múltiplos tópicos, 1 projeto com pontos de entrega e referências.

---

## Roadmap Full Stack WebDev - Pleno -> Senior

Guia estruturado de 18 meses para desenvolvedores full stack que querem alcançar senioridade real. TypeScript, Node.js, React, arquitetura, testes, segurança, cloud e liderança técnica.

### Fases

| #   | Fase                | Período       |
| --- | ------------------- | ------------- |
| 00  | Linux, Terminal     | 2-3 semanas   |
| 02  | C Básico            | 3-4 semanas   |
| 03  | Ponteiros & Memória | 4-6 semanas   |
| 04  | C Avançado          | 5-7 semanas   |
| 05  | Assembly            | 6-8 semanas   |
| 06  | SOs                 | 7-9 semanas   |
| 07  | Redes & Protocolos  | 5-7 semanas   |
| 08  | C++ Moderno         | 8-10 semanas  |
| 09  | Rust                | 10-14 semanas |
| 10  | Especialização      | ongoing       |

# Roadmap Low-Level

Guia estruturado para devs full stack que querem entender o que acontece por baixo do Node.js, do V8, e de todo JavaScript. Começa do zero — terminal, Linux, C básico — passa por ponteiros e memória com calma, e vai até Rust e sistemas operacionais.
